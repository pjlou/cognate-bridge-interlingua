# Corrected pronunciations
#
# When browser TTS is flagged wrong for every stand-in voice on a headword,
# the Study page looks here for a replacement clip:
#
#   tts-corrections/{bridgeCode}/{headword}.wav
#
# Example: Interlingua "aqua" → `ia/aqua.wav`
#
# Filenames are lowercase. Use WAV (audio/wav). After adding a file, restart
# or hard-refresh the client so the static asset is served.
